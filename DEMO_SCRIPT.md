# FunWiki — 2-Minute Demo Script

Total: ~120 seconds. Start with the app loaded on "Black Holes".

## 0:00–0:20 — The problem (show, don't tell)
- Open a Wikipedia article in another tab: wall of text, 40+ blue links.
- "Nobody explores like this. What if Wikipedia felt like exploring?"
- Switch to FunWiki. Search "Black Holes" → knowledge map blooms.

## 0:20–0:50 — The map (core interaction)
- Click "Event horizon" node → side panel reads the summary + thumbnail.
- Double-click it → branch grows live. "Every click is a rabbit hole, visualized."
- Copy share link, paste in a fresh tab → same topic loads. (Shareability.)

## 0:50–1:20 — The AI layer (Meta)
- Summary tab → "Explain simply" → AI summary at a 5-year-old level.
  (With key: live Muse Spark. Without: say "graceful Wikipedia fallback, cached".)
- Learning path tab → "Build my learning path" → 5-step trail appears.
  Click step 2 → map re-centers. "A curriculum generated from the link graph."

## 1:20–1:45 — The fun (quiz)
- Quiz tab → "Test me!" → answer 3 questions live, score appears.
- "Reading → path → testing: a full learning loop in one page."

## 1:45–2:00 — Close (judges)
- "One proxy, three Meta AI endpoints, zero Wikipedia keys needed."
- Architecture in one breath: React SVG graph → Express proxy (cache) →
  Wikipedia APIs + Meta Model API. "Thank you — go get lost. On purpose."

## Backup lines (if something fails live)
- No network: "Every AI call caches — the second load is instant."
- No API key: "Fallbacks keep the whole demo working offline from Meta."
